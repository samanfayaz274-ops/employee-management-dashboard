# Employee Management Dashboard

A modern and responsive Employee Management Dashboard built with **React, TypeScript, and Tailwind CSS**. This project provides an intuitive interface for managing employee records with dashboard analytics, search functionality, department and status filtering, and CRUD operations.

---

## Preview

The dashboard includes:

- Employee statistics
- Search employees
- Department filtering
- Status filtering
- Add employee functionality
- Delete employee functionality
- Responsive table layout

---

## Features

### Dashboard Analytics

- Total Employees Count
- Active Employees Count
- Total Departments Count
- Average Salary Calculation

### Employee Management

- Add New Employee
- Delete Employee
- View Employee Records

### Search & Filtering

- Search employees by name
- Filter by department
- Filter by status (Active/Inactive)

### User Interface

- Modern and clean design
- Fully responsive layout
- Simple and intuitive navigation
- Fast rendering with React
